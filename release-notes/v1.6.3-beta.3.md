**Radio Dash 1.6.3 beta 3**

- **Android Auto button follows MG4Dash** ([#5](https://github.com/Skittle6938/MG4Radio/issues/5)): the button of Radio Dash's bars always opened Android Auto. It now opens what MG4Dash's own button opens (Android Auto, CarPlay or the app chosen by a long press on it in MG4Dash), and the bottom bar shows *CarPlay* or the app's name. Needs MG4Dash 1.7.3 beta 24 or later; with an older MG4Dash the button keeps opening Android Auto.

Install from MG4Dash (Settings > System > Update > Update Radio Dash, with beta versions on), or like before (`adb push` + `pm install -r -f`, or USB stick), then **reboot the head unit** (hold Home about 20 s): the steering wheel buttons don't reach the radio until you do.
