**Radio Dash 1.6.5 beta 2**

- The Home button in the Radio Dash toolbar now opens MG4Dash, even when the SAIC launcher is set as the default. [MG4Dash #153](https://github.com/Skittle6938/MG4Dash/issues/153)

Install from MG4Dash (Settings > System > Update > Update Radio Dash, with beta versions enabled), then reboot the head unit so the steering wheel buttons reach the radio.
