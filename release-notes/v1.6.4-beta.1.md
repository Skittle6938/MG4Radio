**This update downloads about 8.6 MB of data: better on Wi-Fi from a phone hotspot, or over USB if possible.**

**Radio Dash 1.6.4 beta 1**

- **24 colours**: Radio Dash follows the new background and button colours of MG4Dash (24 of each instead of 5, backgrounds more clearly tinted), in dark and light mode. Needs MG4Dash 1.7.4 beta 19 or later; with an older MG4Dash, the 5 colours work as before.
- **Vertical bar the same size as MG4Dash's**: same width (normal and wide bar), same distance from the screen edge, and same place under the fog light button, so the bar no longer moves when you switch between MG4Dash and the radio.

Install from MG4Dash (Settings > System > Update > Update Radio Dash, with beta versions on), or like before (`adb push` + `pm install -r -f`, or USB stick), then **reboot the head unit** (hold Home about 20 s): the steering wheel buttons don't reach the radio until you do.
